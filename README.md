# 🛠️ Python Security & Penetration Testing Tools

A collection of lightweight Python scripts created for automation in web reconnaissance and security testing.

## 🚀 Tools Included

### 1. `PyDirbuster.py`
* **Description:** A custom directory brute-forcing tool designed to discover hidden paths and files on web servers.
* **Features:** Multithreaded requests, custom wordlist support, and HTTP status code filtering.

### 2. `Subdomain_Scanner.py`
* **Description:** A fast reconnaissance script for enumerating subdomains of a target domain.
* **Features:** Passive and active DNS querying to expand the attack surface during web assessments.

### 3. `port_scanner.py`
* **Description:** A socket-based network port scanner to identify open ports and running services on a target host.
* **Features:** Fast TCP port scanning with clear output logs.
